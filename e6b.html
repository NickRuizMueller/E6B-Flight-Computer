Wie das funktioniert
Eine Umdrehung = eine Dekade (10 → 100), Winkel = 360° · log₁₀(v/10). Die Scheibe wird so gedreht, dass der Bezugswert der Innenskala (60) unter dem gewünschten Außenwert liegt. Dann gilt an jeder Strahllinie: außen = innen · a / b. Beispiel: 60 unter 180 km/h → bei 90 min auf der Innenskala stehen 270 km außen. Das ist genau die Bedienung des mechanischen E6B, nur ohne Lupe.
